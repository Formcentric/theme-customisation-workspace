# Formcentric-Theme-Customisation-Workspace

Im Formcentric-Theme-Customisation-Workspace finden Sie das Toolkit, das alle notwendigen Werkzeuge für die Anpassung von Formcentric-Themes bereitstellt. Sie können entweder bestehende Themes modifizieren oder eigene Varianten erstellen. Passen Sie dazu Theme-Variablen, SCSS-Partials und JavaScript-Templates an, um Design, Markup und Styling Ihrer Formulare nach Bedarf zu konfigurieren. Integrieren Sie eigene Schriftarten und Bilder und exportieren Sie Ihre Anpassungen für verschiedene Zielumgebungen.

## Warum diesen Workspace verwenden?

- **Flexibel** – Nehmen Sie Anpassungen auf der Ebene vor, die für Sie sinnvoll ist.
- **Wartbar** – Nutzen Sie einen strukturierten Ansatz für Theme-Entwicklung.
- **Professionell** – Bauen Sie auf offiziellen Formcentric-Themes auf.
- **Effizient** – Live-Vorschau & Hot Reloading für schnelle Entwicklung.
